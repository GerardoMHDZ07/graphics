Ejercicio 1

Cuadrados en Espiral — Interpolación de Vértices

Algoritmo: Interpolación lineal de vértices TypeScript + Canvas API

¿Cómo funciona?

Dado un cuadrado con vértices A, B, C, D, en cada iteración cada vértice se desplaza un porcentaje q hacia el siguiente vértice. Esto produce una rotación y reducción progresiva, generando el efecto de espiral. El parámetro q = 0.08 controla la velocidad de giro.

● Cuadrado central ● Superior izq. ● Superior der. ● Inferior izq. ● Inferior der.
